# High-Recall Coverage Checklist

Use this checklist when comprehensiveness matters.

1. Review question and inclusion criteria are explicit.
2. Domain coverage matrix was created before main screening.
3. Every major domain in scope appears in the domain coverage matrix.
4. Sentinel-paper set was created before main screening.
5. Sentinel papers cover the main concept variants.
6. The latest major review/meta-analysis was checked for each major domain.
7. Review supersession audit was completed.
8. Benchmark recall set was created.
9. Benchmark recall results were completed.
10. More than one query family was used.
11. More than one source/database was used where available.
12. Search strings were logged.
13. Master candidate pool was deduped with source provenance preserved.
14. Candidate pool was reconciled against expert-submitted references.
15. Candidate pool was reconciled against prior reviews.
16. Candidate pool was reconciled against major authors.
17. Backward citation chasing was completed.
18. Forward citation chasing was completed.
19. Related-article expansion or equivalent was attempted where available.
20. Missing important papers were classified by failure mode.
21. Coverage artifacts were written to `reports/` or approved sheets.
22. Screening exclusions used explicit reasons.
23. QA rounds 1, 2, and 3 all passed.
24. Saved-file verification passed inside the VM.
25. Saved-file verification passed again after sync-back to the host.
26. Final gap analysis stated whether any unresolved misses remain.
27. `validate_high_recall_reports.py` passed inside the VM or after sync-back.
